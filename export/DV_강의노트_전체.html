4. 꾸미기 함수 (scripting vs artist)

하고 싶은 것 Scripting (plt.) Artist (ax.)
제목 plt.title() ax.set_title()
x축 이름 plt.xlabel() ax.set_xlabel()
y축 이름 plt.ylabel() ax.set_ylabel()
텍스트 plt.text(x, y, '글') —
화살표/주석 plt.annotate(s, xy, xytext, arrowprops=) —
범례 plt.legend(labels=, loc=) ax.legend()
표시 plt.show() (꾸미기는 show 앞에)

ax = df.plot(...) 으로 Axes를 받으면 artist 방식, 겹쳐 그리기는 plot(..., ax=ax0). Subplot: fig = plt.figure(); ax0 = fig.add_subplot(1, 2, 1) → df.plot(..., ax=ax0).

7. Box plot / 이상치

  • 5수: min, Q1, median, Q3, max / IQR = Q3 − Q1
  • 이상치: > Q3 + 1.5×IQR 또는 < Q1 − 1.5×IQR
  • 한 나라만 DataFrame으로: .loc[['Japan'], years] (대괄호 두 겹) → describe() 가능

6. HBM (High Bandwidth Memory) 와 GPU 데이터 흐름 (슬라이드 39~44)

  • 📘 HBM = High Bandwidth Memory, GPU 바로 옆에 붙은 초고대역폭 메모리 (슬라이드 41~42: GPU 칩 주변에 HBM이 붙은 그림)

GPU 연산 시 데이터 흐름 (LLM 학습 예)

  1. SSD → CPU RAM: 학습 데이터가 SSD에서 시스템 RAM으로 로딩
  2. CPU RAM → HBM: PyTorch의 tensor.to("cuda") 가 데이터를 GPU용 HBM으로 복사
  3. HBM → GPU 연산 유닛: Tensor Core / CUDA Core가 연산에 필요한 데이터를 HBM에서 읽음
  • 📘 “4.8 TB/s” 같은 HBM bandwidth는 주로 3단계(HBM → GPU 연산 유닛) 의 전송 속도.

단순화 예: Y = XW

  • X(input/activation) → HBM, W(model weights) → HBM → Tensor Core가 XW 계산 → 결과 Y → 다시 HBM. 이것이 엄청난 속도로 반복.
  • 📘 그래서 LLM에서는 계산 성능(TFLOPS/PFLOPS)만큼 HBM bandwidth가 중요.
  • 📘 Tensor Core가 아무리 빨라도 HBM이 데이터를 제때 못 주면 Tensor Core가 논다 → memory bottleneck(메모리 병목).

  • 📘 NVIDIA H100 / H200: OpenAI 대규모 AI 학습 인프라에 사용. GPT-5.2는 H100, H200, GB200-NVL72 기반 인프라로 개발됐다고 OpenAI가 공식 발표 → GPT-5 세대의 핵심 학습 인프라.
  • 📘 GB200 (Blackwell): 최근 OpenAI 프런티어 모델 학습이 Hopper(H100/H200) → Blackwell(GB200) 로 이동. Stargate 미국 Abilene 데이터센터는 GB200 기반, GPT-5.5가 여기서 학습됐다고 공식 발표.
  • 📘 Vera Rubin: OpenAI–NVIDIA, 최소 10 GW 규모 NVIDIA 시스템 구축 파트너십. 첫 1 GW는 2026년 하반기 Vera Rubin 플랫폼 기반 예정(장기적으로 수백만 개 GPU 규모).
  • 💡 세대 순서: Hopper(H100/H200) → Blackwell(B200/GB200) → Rubin(Vera Rubin).

DV_04 — Plot 종류와 시각화 라이브러리 (Plots & Libraries 1)

표기: 📘 = 슬라이드 / 💡 = 이해용 주석 / ➕ = 슬라이드에 없는 추가 설명 이 강의는 개념 중심 (코드 실습은 DV_05 이후). 시험에서 “어떤 plot을 언제 쓰나 / 어떤 함정이 있나 / 어떤 라이브러리가 무엇에 좋나”로 출제 가능성 높음.

0. Plot 이란? (슬라이드 2~3)

  • 📘 데이터를 시각적 형태로 표현 / 정보·추세·통찰을 효과적으로 전달 / 패턴 발견·추세 식별 / 복잡한 정보를 더 쉽게 이해
  • 📘 이 강의의 5가지 plot: Line, Bar, Scatter, Box, Histogram

1. 5가지 Plot 한눈에 비교

Plot 한 줄 정의 쓰는 변수(데이터) 대표 용도 주의할 함정
Line 데이터 점들을 직선으로 연결 x: 연속형(주로 시간), y: 연속값 시간에 따른 추세 y축 시작값(0) 에 따라 오해 유발
Bar 직사각형 막대의 높이/길이로 크기 표현 x: 범주형, y: 수치 (가로/세로 모두 가능) 범주 간 비교, 구성 비율, 순위 y축이 0에서 시작 안 하면 왜곡
Scatter 두 변수의 값을 직교좌표 위 점으로 x: 연속형, y: 연속형 (2개의 연속 변수) 상관관계, 군집, 이상치 이상치가 해석에 큰 영향
Box 분포 + 요약 통계 (IQR 상자, 중앙값 선, 수염, 이상치는 점) y: 연속형, (x: 범주형 그룹) 그룹 간 분포 비교, 퍼짐·왜도, 이상치 이상치를 무시·오처리하면 해석 왜곡
Histogram 구간(bin)별 빈도를 막대로 연속형 변수 1개 분포 모양, 왜도, 변동성 bin 개수 선택에 따라 모양이 달라짐

2. Line Plot (슬라이드 4~5)

  • 📘 정의: 데이터 점들을 직선으로 이어 표시
  • 📘 사용 경우:
    • 시간에 따른 추세 표시
    • 연속적인 독립변수를 가진 데이터셋 비교
    • 인과관계 설명
    • 연속 데이터 시각화
  • 📘 함정: 축의 스케일을 신중히 고르지 않으면 오해를 부를 수 있음.
    • 예: 1998년 이민자 감소 그래프 — y축을 0에서 시작하도록 고치기 전(BEFORE) 에는 급락처럼 보이고, 후(AFTER) 에는 완만한 변화.
  • 💡 y축을 확대(잘라서)하면 작은 변화가 과장돼 보인다 → Line plot도 y축을 0부터 시작해 보는 습관.

3. Bar Plot (슬라이드 6~8)

  • 📘 정의: 직사각형 막대로 데이터 표시, 막대의 높이(길이)가 크기, 세로/가로 모두 가능 (슬라이드 6: 세로 막대 + 가로 막대 예시)
  • 📘 사용 경우:
    • 서로 다른 범주/그룹 비교
    • 뚜렷한 범주를 가진 이산(discrete) 데이터 표시
    • 각 범주가 전체에 기여하는 정도 표시
    • 순위/정렬하기 쉬운 데이터 시각화
  • 📘 함정: 부적절한 막대 선택이나 축 스케일은 오해를 부르는 plot.
    • 예: 1980~2013 아이슬란드 → 캐나다 이민자 — BEFORE: y축이 6에서 시작(막대 길이 차이가 과장) / AFTER: y축을 0에서 시작하도록 교정.
  • 💡 막대 길이 = 값이므로 기준선이 0이어야 비교가 공정. 0이 아닌 곳에서 자르면 길이 비율이 값 비율과 달라짐.

4. Scatter Plot (슬라이드 9~11)

  • 📘 정의: 직교(cartesian) 좌표로 두 변수의 값을 표시. 한 변수 값은 가로축 위치, 다른 변수 값은 세로축 위치를 결정.
  • 📘 사용 경우:
    • 두 연속형 변수 간 관계 조사
    • 데이터의 패턴·추세 조사
    • 이상치(outlier) 또는 특이한 관측값 탐지
    • 데이터 내 군집(cluster) 식별
  • 📘 함정: 이상치가 해석에 큰 영향 → 포함/제외 여부를 고려해야 함. (슬라이드 11: “이상치 있음” vs “이상치 없음” 두 scatter를 비교 — 이상치가 있으면 축 범위가 넓어져 대부분의 점이 한 곳에 뭉쳐 보임.)

5. Box Plot (슬라이드 12~13)

  • 📘 정의: 데이터셋의 분포와 주요 통계량을 표시
  • 📘 구성: 사분위 범위(IQR) = 상자(box), 중앙값(median) 선, 수염(whiskers) = 범위 표시, 이상치 = 수염 밖의 개별 점
  • 슬라이드 12 그림 구성요소: MAXIMUM / UPPER QUARTILE(Q3) / MEDIAN(Q2) / LOWER QUARTILE(Q1) / MINIMUM, 그리고 수염(WHISKERS), 상자(BOX)
  • 📘 사용 경우:
    • 범주/그룹별 연속형 변수의 분포 비교
    • 데이터의 퍼짐(spread)과 왜도(skewness) 확인 — 사분위수 시각화
    • 이상치 식별·분석
    • 요약 통계 시각화
    • 데이터셋의 여러 변수 분포 비교
  • 📘 박스 플롯은 이상치의 존재와 정도를 알려 줌. 이상치를 무시하거나 잘못 다루면 해석이 왜곡되고 중요한 통찰이 가려짐 (scatter와 동일).
  • ➕ IQR = Q3 − Q1. 일반적으로(matplotlib/seaborn 기본) 수염은 Q1 − 1.5×IQR ~ Q3 + 1.5×IQR 범위 안의 가장 먼 데이터까지, 그 밖은 이상치 점으로 표시. 상자가 위/아래로 치우치거나 수염 길이가 비대칭이면 왜도의 단서. (슬라이드에는 1.5×IQR 기준이 없음)

6. Histogram (슬라이드 14~16)

  • 📘 정의: 데이터셋 분포의 그래픽 표현. 구간(interval)별 빈도 또는 상대 빈도를 보여줌. 막대 = 각 구간의 데이터 개수. (슬라이드 14 예: Titanic 데이터의 Age Distribution, x=Age, y=Frequency)
  • 📘 사용 경우: 데이터 분포 이해 / 데이터의 모양 시각화 / 왜도 평가 / 데이터의 변동성·퍼짐 보여주기
  • 📘 함정 — bin(구간) 선택: 난수 데이터로 세 가지 binning 히스토그램 생성 예시
    • Too Few Bins(너무 적음): 모양이 뭉개져 정보 손실
    • Optimal Binning(적절): 분포 모양이 잘 드러남
    • Too Many Bins(너무 많음): 들쭉날쭉해져 노이즈처럼 보임
  • 💡 Bar plot과의 차이(➕): Bar = 범주형 변수의 크기 비교(막대 사이 간격 있음) / Histogram = 연속형 변수를 구간으로 나눈 분포(막대가 붙어 있음).

A-2. Matplotlib 아키텍처 — 3개 레이어 (슬라이드 3~8)

레이어 역할 비유(슬라이드 4)
Scripting Layer (pyplot) 작업과 plot 생성을 단순화하는 가벼운 스크립팅 인터페이스 가볍다
Artist Layer (Artist) 화면의 모든 요소를 객체로 다룸 다른 개발자와 공유하는 무거운 프로그래밍 패러다임
Backend Layer (FigureCanvas, Renderer, Event) 실제로 그리고 입력을 처리 가장 밑바닥
  • 💡 위(사용자와 가까움) → 아래(하드웨어와 가까움) 순: Scripting → Artist → Backend. 이 수업은 Scripting Layer(pyplot) 를 사용.

Backend Layer (슬라이드 5) — 3개의 내장 추상 인터페이스 클래스

  1. FigureCanvas (matplotlib.backend_bases.FigureCanvas): figure가 그려지는 영역
  2. Renderer (matplotlib.backend_bases.Renderer): FigureCanvas 위에 그리는 방법을 아는 객체
  3. Event (matplotlib.backend_bases.Event): 키보드, 마우스 클릭 등 사용자 입력 처리

Artist Layer (슬라이드 6)

  • 📘 핵심 객체는 Artist 하나. Artist는 Renderer를 사용해 canvas에 그리는 법을 안다.
  • 📘 제목, 선, 눈금 라벨, 이미지 등이 각각 개별 Artist 인스턴스
  • 📘 Artist 두 종류:
    • Primitive(기본 요소): 선 Line2D, 텍스트 Text, 사각형 Rectangle
    • Composite(복합 요소): 다른 Artist를 포함·관리 — Axis, Tick, Axes, Figure
  • 📘 복합 Artist는 다른 복합 Artist와 기본 Artist 모두 포함할 수 있음.

Scripting Layer (슬라이드 7~8)

  • 📘 주로 pyplot. Artist layer보다 가벼운 스크립팅 인터페이스

plt.show()

C-3. 시험 대비 포인트

  1. Area plot은 기본 stacked. 겹치게 하려면 stacked=False. 투명도 기본 0.5.
  2. 여러 국가를 그리는 plot(area/hist)은 transpose() 필수 (index=x 또는 관측치, 열=그룹).
  3. np.histogram은 (count, bin_edges) 2개 반환. bin_edges는 xticks=에 넣어 눈금과 bin을 맞춤.
  4. plt.xxx() ↔︎ ax.set_xxx(): scripting vs artist layer. ax = df.plot(...).
  5. bar = 범주 / histogram = 연속. 간격 유무, 순서, 목적 차이 설명할 수 있어야 함 (슬라이드 20).
  6. bar = 세로, barh = 가로. 라벨이 길면 가로.
  7. plt.annotate 좌표(bar의 x)는 연도가 아니라 막대 순번.
  8. 상위 N = sort_values(내림차순).head(N), 하위 N = .tail(N). barh 상위 N을 위에 보이게 하려면 오름차순 + tail(N).
  9. 슬라이드 정의: area = line plot 기반, 크기와 비율 표현.

B-5. Bubble Plot

개념 (셀 85)

  • 📘 bubble plot = scatter plot의 변형으로 3차원(x, y, z) 데이터를 표시. 점 대신 버블을 쓰고, 버블 크기는 세 번째 변수 z(가중치, weight) 가 결정.
  • 📘 Matplotlib에서는 plot()의 s 파라미터에 배열 또는 스칼라(각 점의 가중치)를 넘김.
  • 💻 사례: 아르헨티나 대공황(1998~2002) 영향 — 이웃 브라질과 비교. 가중치는 연도별 이민자 수의 정규화(normalized) 값.

Step 1: 데이터 (셀 86~87) — 국가 열이 되도록 전치 + Year 열 만들기

df_can_t = df_can[years].transpose()          # 행=연도, 열=국가(195개)

Step 2: 정규화 (셀 88~89) — Feature scaling(min-max) 으로 값을 [0, 1]로

X' = (X − X_min) / (X_max − X_min)       → 최댓값 = 1, 최솟값 = 0
norm_brazil    = (df_can_t['Brazil']    - df_can_t['Brazil'].min())    / (df_can_t['Brazil'].max()    - df_can_t['Brazil'].min())
norm_argentina = (df_can_t['Argentina'] - df_can_t['Argentina'].min()) / (df_can_t['Argentina'].max() - df_can_t['Argentina'].min())
  • 💡 정규화 이유: 국가마다 이민자 규모가 다르므로 0~1로 맞춰 버블 크기를 비교 가능하게.

  • 📘 가중치는 s 로 전달. 정규화 값(0~1)은 너무 작아 안 보이므로 ×2000으로 키우고, 최솟값(0)도 보이도록 +10.

  1. Pie: groupby().sum() 필요 / autopct, explode, startangle, pctdistance, labels=None+legend 의미 / plt.axis('equal') = 원형 유지.

  3. Box: 5개 숫자(min, Q1, median, Q3, max) / IQR = Q3−Q1 / 이상치 = Q3+1.5·IQR 초과 또는 Q1−1.5·IQR 미만 / describe()로 수치 확인 / vert=False는 가로.

  5. Subplot: fig.add_subplot(nrows, ncols, plot_number), plot_number는 1부터 행 방향 증가, plot(..., ax=ax0), 축약형 subplot(211) == subplot(2,1,1).
  6. Scatter는 x=, y= 열 이름 지정이 필수. 연도가 index면 reset_index()로 열로.
  7. 회귀선: np.polyfit(x, y, deg=1) → [기울기, 절편] → plt.plot(x, fit[0]*x + fit[1]).
  8. Bubble = scatter + 세 번째 변수(s). 정규화(min-max)로 [0,1] → ×2000 + 10.
  9. 두 plot 겹치기: 첫 plot의 반환값 ax0 → 두번째 plot(..., ax=ax0).
  10. sum(axis=0) = 열별(위→아래) 합, sum(axis=1) = 행별(좌→우) 합.

Step 2. waffle chart 전체 크기

total_num_tiles = width * height     # 400

Step 3. 비율 → 범주별 타일 수

tiles_per_category = (category_proportions * total_num_tiles).round().astype(int)
# Denmark 129, Norway 77, Sweden 194

Step 4. waffle 모양의 행렬(matrix) 만들고 채우기

waffle_chart = np.zeros((height, width), dtype=np.uint)    # 0으로 채운 (10×40) 행렬

category_index = 0
tile_index = 0
for col in range(width):                 # 열 방향(왼→오)으로 먼저
    for row in range(height):            # 각 열을 위→아래로
        tile_index += 1
        # 현재 범주에 할당된 타일 수를 다 채웠으면 다음 범주로
        if tile_index > sum(tiles_per_category[0:category_index]):
            category_index += 1
        waffle_chart[row, col] = category_index     # 범주 번호(1,2,3)를 저장
  • 💡 행렬 값 = 범주 번호(Denmark=1, Norway=2, Sweden=3). 열 단위로 채우므로 같은 범주가 세로 줄 단위로 연속.
  • 💡 tile_index > sum(앞 범주들의 타일 수) 일 때 category_index += 1.

방법 ①: FeatureGroup + CircleMarker로 위치 표시 (셀 51~52)

  • 📘 Folium에서 지도에 데이터 위치를 겹치려면 feature group을 만들어 자체 feature/스타일을 부여한 뒤 지도에 추가.
incidents = folium.map.FeatureGroup()                 # 피처 그룹 생성

for lat, lng, in zip(df_incidents.Y, df_incidents.X):  # 위도(Y), 경도(X)를 짝지어 순회
    incidents.add_child(
        folium.vector_layers.CircleMarker(
            [lat, lng],
            radius=5,              # 원 크기
            color='yellow',        # 테두리색
            fill=True,
            fill_color='blue',     # 채움색
            fill_opacity=0.6))     # 채움 투명도

sanfran_map.add_child(incidents)                       # 그룹을 지도에 추가
  • 💡 zip(a, b) = 두 리스트를 같은 순번끼리 쌍으로 묶어 순회.

방법 ②: 팝업 텍스트 — Marker(popup=) (셀 53~54)

  • 📘 마커 위에 마우스를 올리면(노트북 표현)/클릭하면 범죄 범주(Category) 가 표시되도록.
latitudes  = list(df_incidents.Y)
longitudes = list(df_incidents.X)
labels     = list(df_incidents.Category)

for lat, lng, label in zip(latitudes, longitudes, labels):

sanfran_map.add_child(incidents)

해결책 A (간단): 위치 마커 제거 후 원형 마커 자체에 팝업 (셀 55~56)

해결책 B (정석): MarkerCluster로 묶기 (셀 57~59) ⭐

  • 📘 마커를 군집(cluster) 으로 묶어, 각 클러스터에 그 지역의 범죄 수를 표시. 클러스터는 샌프란시스코의 지역별 묶음(pocket) 으로 따로 분석 가능.
from folium import plugins

sanfran_map = folium.Map(location=[latitude, longitude], zoom_start=12)

incidents = plugins.MarkerCluster().add_to(sanfran_map)      # MarkerCluster 객체를 지도에 추가

for lat, lng, label in zip(df_incidents.Y, df_incidents.X, df_incidents.Category):
    folium.Marker(location=[lat, lng], icon=None, popup=label).add_to(incidents)   # 지도가 아니라 cluster에 추가
sanfran_map
  • 📘 해석: 최대로 축소하면 모든 마커가 하나의 “전역 클러스터(global cluster)” = 100개(전체 범죄 수) 로 합쳐짐. 확대할수록 작은 클러스터로 쪼개지고, 끝까지 확대하면 개별 마커가 됨.
  • 💡 핵심 차이: 일반 마커는 .add_to(지도), 클러스터 마커는 .add_to(cluster).

B-5. Choropleth Map: 세계 이민 지도

개념 (셀 60~61)

  • 📘 Choropleth = 통계 변수의 측정값에 비례해 지역을 음영/무늬로 표시한 주제도. 인구밀도, 1인당 소득 같은 값이 지역별로 어떻게 달라지는지, 한 지역 내 변동 수준을 쉽게 보여줌. (예: 주별 제곱마일당 인구 지도)

데이터 (셀 62~67)

df_can = pd.read_csv('DV_05_data_canada_immigration.csv')
print(df_can.shape)        # (195, 40)

GeoJSON + 기본 지도 (셀 68~69)

  • 📘 Choropleth에는 관심 지역(주/카운티/국가)의 경계를 정의한 GeoJSON 파일이 필요. 세계 지도 → 모든 나라 경계가 있는 GeoJSON.
world_geo = r'DV_09_json_world_countries.json'                 # GeoJSON 파일 경로 (r'' = raw string)
world_map = folium.Map(location=[0, 0], zoom_start=2)         # [0, 0] 중심, 초기 줌 2

choropleth 주요 파라미터 (셀 70~71) ⭐ 시험 단골

파라미터 의미
geo_data GeoJSON 파일(경계 데이터)
data 데이터가 들어 있는 DataFrame
columns choropleth에 쓸 DataFrame의 열 — ['Country', 'Total'] ([키 열, 값 열])
key_on GeoJSON 안에서 관심 변수(국가 이름)를 담은 키. GeoJSON을 텍스트 편집기로 열어 국가 이름이 들어 있는 키를 확인해야 함. 여기서는 name. 대소문자 구분 — GeoJSON에 있는 그대로 'feature.properties.name' 
world_map = folium.Map(location=[56.1304, -106.3468], zoom_start=2)

folium.Choropleth(
    geo_data=world_geo,                   # 경계 GeoJSON 경로/객체
    data=df_can,                          # 국가별 이민 데이터가 든 DataFrame
    columns=['Country', 'Total'],         # 사용할 열
    key_on='feature.properties.name',     # DataFrame의 Country와 GeoJSON의 국가 이름을 연결
    fill_color='YlOrRd',                  # 색 스케일 (노랑-주황-빨강)
    fill_opacity=0.7,                     # 채움 투명도
    line_opacity=0.2,                     # 경계선 투명도
    nan_fill_color='lightgray',           # 결측값(NaN) 국가 색
    nan_fill_opacity=0.4,                 # 결측값 국가 투명도
    legend_name='Immigration to Canada',  # 범례 제목
    reset=True                            # 다시 불러올 때 리셋
).add_to(world_map)
world_map
  • 📘 해석: 범례상 색이 진하고 빨간색에 가까울수록 이민자가 많음. 1980~2013년 가장 많은 이민: China, India, Philippines, 이어서 Poland, Pakistan, 그리고 (흥미롭게도) US.
  • 💡 연결 원리: data의 Country 값 ↔︎ GeoJSON의 feature.properties.name 값이 글자 그대로 일치해야 그 나라가 칠해짐. 일치하지 않으면 NaN → nan_fill_color(회색).
  • 💡 슬라이드는 world_map.choropleth(...)(구 방식), 노트북은 folium.Choropleth(...).add_to(world_map)(신 방식). 파라미터 이름은 동일(geo_data, data, columns, key_on, fill_color, legend_name ...).
  • 📘 확장 아이디어: 개별 연도나 10년 단위로 choropleth를 만들어 전체 기간(1980~2013)과 비교.

C-3. 시험 대비 포인트

  1. Folium = 지리공간 시각화 / 위도·경도 / 마커·클러스터 / 다양한 스타일 / 무료(plotly는 API 호출 제한 가능).
  2. folium.Map(location=[위도, 경도], zoom_start=N, tiles='스타일') — location은 [위도, 경도] 순서, zoom_start↑ = 확대.
  3. tiles로 스타일 변경 (Cartodb dark_matter = 흑백 고대비, Cartodb positron = 밝고 미니멀, Stamen Toner/Terrain, Mapbox Bright = 모든 나라 이름 표시).
  4. popup = 클릭하면 나타나는 라벨. 마커 많으면 → ① CircleMarker에 popup ② MarkerCluster.
  5. MarkerCluster: 전체 축소 시 전역 클러스터(전체 개수, 예: 100), 확대하면 분리 → 개별 마커. 마커를 cluster에 add.
  6. 데이터프레임 X = 경도, Y = 위도 → 지도에는 [Y, X].
  7. Choropleth = 값에 비례해 지역 색칠. GeoJSON 필수. 파라미터 geo_data / data / columns / key_on / fill_color / legend_name. key_on='feature.properties.name'은 대소문자 구분, GeoJSON 키 이름 확인 필요.
  8. 색이 진한 빨강일수록 이민자 많음(YlOrRd). 상위: China, India, Philippines.
  9. GeoJSON 구조: FeatureCollection → features → (properties.name, geometry.Polygon, id).
