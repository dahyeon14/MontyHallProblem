## 4. GPU 이름 읽는 법 (슬라이드 23~28)
📘 **GeForce RTX 5070 = 세대(50) + 성능(70)**
- 앞 두 자리 = **Generation (세대)**: 10, 20, 30, 40, 50 …
- 뒤 두 자리 = **Performance (성능)**: 50~90
- 📘 **세대가 높다고 항상 성능이 좋은 것은 아니다!**
- 📘 **딥러닝**에는 세대가 낮아도 **성능 70 이상** 선택 권장
- 💡 예: RTX 5060(최신 세대, 성능 60) < RTX 4070(이전 세대, 성능 70) 일 수 있음 → 딥러닝은 70 이상이 유리.
- 📘 슬라이드 25~27: GPU 성능 벤치마크 막대그래프, Nvidia GPU 라인업(소비자용 / **Enterprise & Data Center GPU**)

## 5. 데이터센터 GPU: B200 / GB200 / Rubin (슬라이드 29~38)
| 이름 | 의미 |
|---|---|
| **B200** | **Blackwell 아키텍처의 GPU** (B = Blackwell) |
| **GB200** | **Grace CPU 1개 + Blackwell GPU 2개**를 결합한 **Superchip** (G = Grace CPU) → “GPU에 CPU까지 붙여 하나의 AI용 슈퍼칩” |
| **DGX B200** | B200 GPU **8개** 탑재 완제품 서버 |
| **GB200 NVL72** | **Grace CPU 36개 + Blackwell GPU 72개**를 **한 랙**에 구성 |
| **Rubin GPU** | B200의 **다음 세대** GPU |
| **Vera Rubin Superchip** | **Vera CPU 1개 + Rubin GPU 2개** |
| **Vera Rubin NVL72** | **Vera CPU 36개 + Rubin GPU 72개**, 한 랙 |
- 📘 정리: GPU 차원 **B200 → Rubin GPU** / 시스템 차원 **GB200 NVL72 → Vera Rubin NVL72**
- 💡 Blackwell 세대 ↔ Rubin 세대, Grace ↔ Vera (CPU 이름)로 짝을 맞춰 기억.

## 6. HBM (High Bandwidth Memory) 와 GPU 데이터 흐름 (슬라이드 39~44)
- 📘 **HBM** = High Bandwidth Memory, GPU 바로 옆에 붙은 초고대역폭 메모리 (슬라이드 41~42: GPU 칩 주변에 HBM이 붙은 그림)

### GPU 연산 시 데이터 흐름 (LLM 학습 예)
1. **SSD → CPU RAM**: 학습 데이터가 SSD에서 시스템 RAM으로 로딩
2. **CPU RAM → HBM**: PyTorch의 `tensor.to("cuda")` 가 데이터를 GPU용 **HBM**으로 복사
3. **HBM → GPU 연산 유닛**: **Tensor Core / CUDA Core**가 연산에 필요한 데이터를 HBM에서 읽음
- 📘 “**4.8 TB/s**” 같은 **HBM bandwidth**는 주로 **3단계(HBM → GPU 연산 유닛)** 의 전송 속도.

### 단순화 예: Y = XW
- X(input/activation) → HBM, W(model weights) → HBM → **Tensor Core**가 XW 계산 → 결과 Y → 다시 HBM. 이것이 엄청난 속도로 반복.
- 📘 그래서 LLM에서는 **계산 성능(TFLOPS/PFLOPS)만큼 HBM bandwidth가 중요**.
- 📘 Tensor Core가 아무리 빨라도 HBM이 데이터를 제때 못 주면 Tensor Core가 논다 → **memory bottleneck(메모리 병목)**.

## 7. ChatGPT를 위한 GPU (슬라이드 45)
- 📘 **NVIDIA H100 / H200**: OpenAI 대규모 AI 학습 인프라에 사용. GPT-5.2는 H100, H200, GB200-NVL72 기반 인프라로 개발됐다고 OpenAI가 공식 발표 → GPT-5 세대의 핵심 학습 인프라.
- 📘 **GB200 (Blackwell)**: 최근 OpenAI 프런티어 모델 학습이 **Hopper(H100/H200) → Blackwell(GB200)** 로 이동. Stargate 미국 **Abilene** 데이터센터는 GB200 기반, **GPT-5.5**가 여기서 학습됐다고 공식 발표.
- 📘 **Vera Rubin**: OpenAI–NVIDIA, 최소 **10 GW** 규모 NVIDIA 시스템 구축 파트너십. 첫 **1 GW**는 **2026년 하반기** Vera Rubin 플랫폼 기반 예정(장기적으로 수백만 개 GPU 규모).
- 💡 세대 순서: Hopper(H100/H200) → Blackwell(B200/GB200) → Rubin(Vera Rubin).

## 8. CPU vs GPU & 시각화에 GPU가 좋은 이유 (슬라이드 46~47)
- 📘 **CPU**: 개수는 적지만 **똑똑한(복잡한 작업을 잘하는) 두뇌**
- 📘 **GPU**: 하나하나는 덜 똑똑하지만 **엄청 많다**
- 📘 시각화에 GPU가 유리한 이유: **이미지는 픽셀(pixel)들로 구성**됨 (원 그림을 픽셀 격자로 확대한 슬라이드)
- 💡 수많은 픽셀에 **같은 단순 계산을 동시에(병렬로)** 해야 하므로, 단순 연산 코어가 많은 GPU가 적합.
