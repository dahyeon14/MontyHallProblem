## 2. Plot 종류별 한 줄 요약 + 코드

| Plot | 언제 | 데이터 모양 | 핵심 코드 |
|---|---|---|---|
| **Line** | 시간에 따른 추세 | index=x(연도), 열=선 | `df.plot(kind='line')` |
| **Area** | 누적 합/비율 추세 | line과 동일 (기본 stacked) | `df.plot(kind='area', stacked=, alpha=)` |
| **Histogram** | 연속형 1변수의 분포 | 열 하나 (Series) | `df['2013'].plot(kind='hist', bins=, xticks=bin_edges)` |
| **Bar / Barh** | 범주 간 값 비교 | index=범주, 값 하나 | `s.plot(kind='bar')` / `'barh'` |
| **Pie** | 전체 중 비율 | `groupby().sum()`의 한 열 | `df['Total'].plot(kind='pie', autopct='%1.1f%%')` |
| **Box** | 분포(5수 요약)와 이상치 | 열 = 그룹 (`transpose()`) | `df.plot(kind='box', vert=)` |
| **Scatter** | 두 연속변수 관계 | **x, y 열 이름 지정** | `df.plot(kind='scatter', x='year', y='total')` |
| **Bubble** | scatter + 3번째 변수(크기) | 정규화한 가중치 | `scatter(..., s=norm*2000+10, ax=ax0)` |
| **Waffle** | 범주 비율을 타일로 | 범주별 값 | `plt.figure(FigureClass=Waffle, rows, columns, values)` |
| **Word cloud** | 텍스트 단어 빈도 | 문자열 | `WordCloud(stopwords, mask).generate(text)` |
| **countplot** | 범주별 개수 | 범주형 열 (**y 없음**) | `sns.countplot(x=, data=)` |
| **barplot** | 범주별 평균 + CI | 범주 x, 수치 y | `sns.barplot(x=, y=, data=)` |
| **regplot** | scatter + 회귀선 + CI | 수치 x, 수치 y | `sns.regplot(x=, y=, data=, ci=95)` |
| **Folium 지도** | 위치/지역 시각화 | 위도·경도 / GeoJSON | `folium.Map(location=[위도,경도], zoom_start=)` |

## 4. 꾸미기 함수 (scripting vs artist)
| 하고 싶은 것 | Scripting (`plt.`) | Artist (`ax.`) |
|---|---|---|
| 제목 | `plt.title()` | `ax.set_title()` |
| x축 이름 | `plt.xlabel()` | `ax.set_xlabel()` |
| y축 이름 | `plt.ylabel()` | `ax.set_ylabel()` |
| 텍스트 | `plt.text(x, y, '글')` | — |
| 화살표/주석 | `plt.annotate(s, xy, xytext, arrowprops=)` | — |
| 범례 | `plt.legend(labels=, loc=)` | `ax.legend()` |
| 표시 | `plt.show()` (**꾸미기는 show 앞에**) | |
> `ax = df.plot(...)` 으로 Axes를 받으면 artist 방식, 겹쳐 그리기는 `plot(..., ax=ax0)`.
> Subplot: `fig = plt.figure(); ax0 = fig.add_subplot(1, 2, 1)` → `df.plot(..., ax=ax0)`.

## 5. 파라미터 사전 (plot() 공통)
| 파라미터 | 의미 | 쓰는 plot |
|---|---|---|
| `kind` | plot 종류 | 전부 |
| `figsize=(w,h)` | 그림 크기 | 전부 |
| `alpha` | 투명도 0~1 | area, hist, scatter |
| `stacked` | 쌓기 | area(기본 True), hist |
| `bins` | 구간 수 | hist |
| `xticks=bin_edges` | 눈금을 bin 경계에 | hist |
| `xlim=(min,max)` | x 범위 | hist, scatter |
| `color`, `edgecolor` | 색 | hist, bar, box, scatter |
| `rot` | 눈금 글자 회전 | bar |
| `vert=False` | 가로 방향 | box |
| `s` | 점(버블) 크기 | scatter |
| `autopct`, `startangle`, `shadow`, `labels=None`, `pctdistance`, `explode`, `colors` | pie 꾸미기 | pie |
| `ax` | 그릴 Axes | 전부 |

## 6. 개념 비교표

### Histogram vs Bar
| | Histogram | Bar |
|---|---|---|
| 데이터 | 연속형 | 범주형 |
| 간격 | 없음 | 있음 |
| 순서 | 유지 | 변경 가능 |
| 목적 | 분포 | 범주 비교 |

### Matplotlib vs Seaborn
| | Matplotlib | Seaborn |
|---|---|---|
| 표현력 | 완전 커스터마이징 | 통계 표현 기본 제공 |
| 디자인 | 투박, 직접 꾸밈 | 깔끔 |
| 통계 | 별도 라이브러리 | boxplot/violin/regression 자동 |
| 코드 | 길다 | 짧다 |
| 데이터 | numpy 배열 | pandas DataFrame (열 이름) |

### stacked vs unstacked area
- stacked(기본): 쌓아서 전체 합과 기여도 / unstacked: `stacked=False`, 겹침 (기본 alpha 0.5)

### countplot vs barplot
- countplot: y 없음, **개수** / barplot: y 지정, **평균 + 신뢰구간**

## 7. Box plot / 이상치
- 5수: min, Q1, median, Q3, max / **IQR = Q3 − Q1**
- **이상치: > Q3 + 1.5×IQR 또는 < Q1 − 1.5×IQR**
- 한 나라만 DataFrame으로: `.loc[['Japan'], years]` (대괄호 두 겹) → `describe()` 가능

## 8. Matplotlib 아키텍처
- **Backend**(FigureCanvas, Renderer, Event) → **Artist**(Primitive: Line2D, Text, Rectangle / Composite: Axis, Tick, Axes, Figure) → **Scripting(pyplot)**
- 만든 사람 John Hunter, EEG/ECoG 시각화에서 시작

## 9. 그래프 함정 (DV_04)
| Plot | 함정 | 해결 |
|---|---|---|
| Line / Bar | y축 시작값이 0이 아님 → 변화 과장 | y축 0부터 |
| Scatter | 이상치 | 포함·제외 판단 |
| Box | 이상치 무시 | 정보 활용 |
| Histogram | bin 수 | too few / optimal / too many |

## 10. 회귀·정규화·누적
- 회귀선: `fit = np.polyfit(x, y, deg=1)` → `[기울기, 절편]` → `plt.plot(x, fit[0]*x + fit[1])`
- CI: 신뢰수준 높을수록(99%) 음영 폭 ↑
- `plt.text(x, y, ...)`: x축이 int면 값, str(막대)면 **순번**
