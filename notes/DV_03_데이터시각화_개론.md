# DV_03 — 데이터 시각화 개론 (Intro to Data Visualization)

> 표기: 📘 = 슬라이드 / 💡 = 이해용 주석 / ➕ = 추가 설명

## 핵심 한 줄
**시각화가 효과적인 이유 = 사람은 시각 정보를 가장 빠르게 처리 + 큰 데이터를 압축 + 숨은 패턴이 드러남 → 의사결정에 도움.**

## 1. 우리 주변의 시각화 (슬라이드 2~5)
- 📘 지도(내비게이션 경로), 태풍 진로 지도 등 일상에 시각화가 이미 깊이 들어와 있음.

## 2. 왜 시각화가 이해하기 쉬운가? (슬라이드 6~9)
### 감각별 정보 처리량 (슬라이드 7~8)
- 📘 덴마크 물리학자 **Tor Nørretranders**: 사람이 시간당 처리하는 정보량은 감각 입력마다 다름. 감각 처리를 컴퓨터 시스템에 비유 (David McCandless의 TED Talk 도표).

| 감각 | 비유 |
|---|---|
| **시각 (sight)** | 약 **1,250 MB/s** ≈ **컴퓨터 네트워크(network)** |
| 촉각 (touch) | **USB** 연결 |
| 청각·후각 (hearing, smell) | **하드디스크(hard disk)** |
- 📘 한눈에 봐도 **시각이 다른 감각보다 시간당 훨씬 많은 정보를 처리**.

### 텍스트 vs 그래픽 (슬라이드 9)
- 📘 **3M** 연구: 그래픽은 텍스트보다 **60,000배 빨리** 처리됨
- 📘 **Dan Zarrella (HubSpot)**: 이미지가 있는 트윗은 없는 트윗보다 **95% 더 많이 리트윗**됨

## 3. 사례 ① 미국인은 하루를 어떻게 보내나 (NYT) (슬라이드 10~13)
- 📘 **2008 American Time Use Survey (Bureau of Labor Statistics)**: 수면, 집안일 등 활동 범주별 하루 시간 → **표만 보면 특별한 통찰 찾기 어려움**
- 📘 **New York Times**의 시각화: 
  - 활동(식사, 일, 집안일, 이동, TV·영화, 사교 …)마다 **고유한 색**
  - 활동에 쓴 시간 = **면적 크기**
  - 우측 상단에서 직업·성별·인종별로 세분화 → **클릭하면 집단별 하루** 확인 (인터랙티브)
- 📘 발견: **취업자 vs 실업자** — TV 시청 시간은 비슷(진한 갈색 영역) / 취업자는 **일 시간 훨씬 많고 교육 시간 적음** / 취업자 **식사 시간이 더 규칙적**
- 📘 결론: **수학·통계 배경이 없어도** 표로는 알기 어려운 패턴·통찰 발견 가능.

## 4. 사례 ② Million Dollar Blocks (슬라이드 14~15)
- 📘 **Columbia University Center for Spatial Research (Laura Kurgan)**: 미국 수감 비용과 수감자 거주지 연구
- 📘 거주지별 수감 비용 지도 — **수감 비용이 클수록 더 밝은 빨강**
- 📘 발견: 비용이 **특정 지역에 심하게 집중**. 가장 밝은 곳은 뉴욕 브루클린의 **11개 블록**으로 2003년 한 해에만 **150억 원 이상**(슬라이드 표기). 이 지역은 **교육 등 공공 자원이 부족**.
- 📘 시각화가 **지역사회의 중요한 문제를 식별**하도록 도움.

## 5. 의사결정을 위한 시각화 (슬라이드 16)
시각화가 의사결정을 돕는 이유 3가지:
1. **대량의 데이터를 압축** — 수천 행을 하나의 그림으로 → 큰 그림을 한눈에
2. **이해하기 쉬움** — 과학·수학·통계 배경 없이도 이해
3. **뇌는 시각 정보 처리에 뛰어남** — 숨은 통찰·패턴을 발견, 복잡한 데이터를 직관적으로 이해해 의사결정

## 6. 사례 ③ Ghost Map — 콜레라 (슬라이드 17~19)
- 📘 **1854년 런던 콜레라**: 10일 만에 500명 이상 사망. 당시 정부는 **악취(냄새)가 원인**이라 믿고 시민들에게 하수를 **템스강에 버리라** 지시 → 강물이 식수라 **오히려 악화**.
- 📘 의사 **John Snow**: 오래전부터 **오염된 물로 전염**된다고 주장했으나 무시당함. 발병 지역 주민을 조사해 **주소별 사망자 수를 검은 막대로 표시한 지도** 제작.
- 📘 지도가 보여준 패턴: **중앙 우물(water pump)에서 멀수록 사망자가 적음** → 펌프가 오염원.
- 📘 결과: 정부가 물을 통한 전염 인정 → **정수 시설 건설, 물 끓여 마시기** 지시 → 런던 콜레라 종식.
- 💡 핵심: “지도(위치 데이터) 시각화가 가설을 증명하고 정책을 바꾼 사례”.

## 7. 사례 ④ 코로나 시뮬레이션 (Washington Post) (슬라이드 20~23)
- 📘 그래픽 기자 **Harry Stevens**: 가상 바이러스로 **사회적 거리두기** 효과 시뮬레이션.
- 📘 가정: 건강한 사람도 감염자와 **접촉만 해도 감염** / 완전히 회복한 사람은 **전파·재감염 없음** / **점 하나 = 한 사람** / 점은 무작위 방향 이동 / **감염자 1명**에서 시작 / 인구 **200명**.
- 📘 빨간 곡선(감염자 수)이 가파르게 상승하다가 회복자가 늘면서 감소.
- 📘 4가지 시나리오: **Free-for-all / Attempted quarantine / Moderate distancing / Extensive distancing** → **Extensive distancing(강력한 거리두기)** 이 가장 효과적.
- 📘 Obama 전 대통령이 트위터로 공유, **Washington Post 역사상 가장 많이 읽힌 기사**.

## 8. 적절한 시각화가 중요한 이유 (슬라이드 24)
- 📘 시각화는 이미 일상에 통합 (날씨, 교통 정보, 선거 결과 …)
- 📘 데이터가 많고 복잡해질수록 **패턴·통찰을 이해하는 것**의 중요성 증가
- 📘 전문 수준과 무관하게 누구나 이해 → **데이터 기반 의사결정** 촉진
- 📘 하지만 **모든 시각화가 직관적이거나 가치 있는 것은 아님** → 시각화 과정이 **제대로 설계되지 않았을 때** 발생 → **올바른 시각화 기법을 배우는 것이 중요**.
