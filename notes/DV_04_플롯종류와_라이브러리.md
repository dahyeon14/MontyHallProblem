## 0. Plot 이란? (슬라이드 2~3)
- 📘 데이터를 시각적 형태로 표현 / 정보·추세·통찰을 효과적으로 전달 / 패턴 발견·추세 식별 / 복잡한 정보를 더 쉽게 이해
- 📘 이 강의의 5가지 plot: **Line, Bar, Scatter, Box, Histogram**

## 1. 5가지 Plot 한눈에 비교

| Plot | 한 줄 정의 | 쓰는 변수(데이터) | 대표 용도 | 주의할 함정 |
|---|---|---|---|---|
| **Line** | 데이터 점들을 **직선으로 연결** | x: 연속형(주로 **시간**), y: 연속값 | 시간에 따른 추세 | **y축 시작값(0)** 에 따라 오해 유발 |
| **Bar** | **직사각형 막대**의 높이/길이로 크기 표현 | x: **범주형**, y: 수치 (가로/세로 모두 가능) | 범주 간 비교, 구성 비율, 순위 | **y축이 0에서 시작 안 하면** 왜곡 |
| **Scatter** | 두 변수의 값을 **직교좌표 위 점**으로 | x: 연속형, y: 연속형 (**2개의 연속 변수**) | 상관관계, 군집, 이상치 | **이상치**가 해석에 큰 영향 |
| **Box** | 분포 + 요약 통계 (**IQR 상자, 중앙값 선, 수염**, 이상치는 점) | y: 연속형, (x: 범주형 그룹) | 그룹 간 분포 비교, 퍼짐·왜도, 이상치 | 이상치를 무시·오처리하면 해석 왜곡 |
| **Histogram** | **구간(bin)별 빈도**를 막대로 | 연속형 변수 **1개** | 분포 모양, 왜도, 변동성 | **bin 개수 선택**에 따라 모양이 달라짐 |

## 2. Line Plot (슬라이드 4~5)
- 📘 정의: 데이터 점들을 **직선으로 이어** 표시
- 📘 사용 경우:
  - **시간에 따른 추세** 표시
  - **연속적인 독립변수**를 가진 데이터셋 비교
  - **인과관계** 설명
  - **연속 데이터** 시각화
- 📘 **함정**: 축의 스케일을 신중히 고르지 않으면 **오해를 부를 수 있음**.
  - 예: **1998년 이민자 감소** 그래프 — y축을 0에서 시작하도록 고치기 **전(BEFORE)** 에는 급락처럼 보이고, **후(AFTER)** 에는 완만한 변화.
- 💡 y축을 확대(잘라서)하면 작은 변화가 과장돼 보인다 → **Line plot도 y축을 0부터** 시작해 보는 습관.

## 3. Bar Plot (슬라이드 6~8)
- 📘 정의: **직사각형 막대**로 데이터 표시, **막대의 높이(길이)가 크기**, **세로/가로** 모두 가능 (슬라이드 6: 세로 막대 + 가로 막대 예시)
- 📘 사용 경우:
  - **서로 다른 범주/그룹 비교**
  - 뚜렷한 범주를 가진 **이산(discrete) 데이터** 표시
  - 각 범주가 **전체에 기여하는 정도** 표시
  - **순위/정렬**하기 쉬운 데이터 시각화
- 📘 **함정**: 부적절한 막대 선택이나 축 스케일은 **오해를 부르는 plot**.
  - 예: **1980~2013 아이슬란드 → 캐나다 이민자** — BEFORE: y축이 **6에서 시작**(막대 길이 차이가 과장) / AFTER: **y축을 0에서 시작**하도록 교정.
- 💡 막대 길이 = 값이므로 **기준선이 0이어야 비교가 공정**. 0이 아닌 곳에서 자르면 길이 비율이 값 비율과 달라짐.

## 4. Scatter Plot (슬라이드 9~11)
- 📘 정의: **직교(cartesian) 좌표**로 **두 변수**의 값을 표시. 한 변수 값은 **가로축 위치**, 다른 변수 값은 **세로축 위치**를 결정.
- 📘 사용 경우:
  - **두 연속형 변수 간 관계** 조사
  - 데이터의 **패턴·추세** 조사
  - **이상치(outlier)** 또는 특이한 관측값 탐지
  - 데이터 내 **군집(cluster)** 식별
- 📘 **함정**: **이상치가 해석에 큰 영향** → 포함/제외 여부를 **고려**해야 함. (슬라이드 11: “이상치 있음” vs “이상치 없음” 두 scatter를 비교 — 이상치가 있으면 축 범위가 넓어져 대부분의 점이 한 곳에 뭉쳐 보임.)

## 5. Box Plot (슬라이드 12~13)
- 📘 정의: 데이터셋의 **분포와 주요 통계량**을 표시
- 📘 구성: **사분위 범위(IQR)** = **상자(box)**, **중앙값(median) 선**, **수염(whiskers)** = 범위 표시, **이상치** = 수염 밖의 **개별 점**
- 슬라이드 12 그림 구성요소: **MAXIMUM / UPPER QUARTILE(Q3) / MEDIAN(Q2) / LOWER QUARTILE(Q1) / MINIMUM**, 그리고 수염(WHISKERS), 상자(BOX)
- 📘 사용 경우:
  - **범주/그룹별 연속형 변수의 분포 비교**
  - 데이터의 **퍼짐(spread)과 왜도(skewness)** 확인 — 사분위수 시각화
  - **이상치** 식별·분석
  - **요약 통계** 시각화
  - 데이터셋의 **여러 변수 분포 비교**
- 📘 박스 플롯은 이상치의 **존재와 정도**를 알려 줌. 이상치를 **무시하거나 잘못 다루면** 해석이 왜곡되고 중요한 통찰이 가려짐 (scatter와 동일).
- ➕ IQR = Q3 − Q1. 일반적으로(matplotlib/seaborn 기본) 수염은 **Q1 − 1.5×IQR ~ Q3 + 1.5×IQR 범위 안의 가장 먼 데이터**까지, 그 밖은 이상치 점으로 표시. 상자가 위/아래로 치우치거나 수염 길이가 비대칭이면 **왜도**의 단서. (슬라이드에는 1.5×IQR 기준이 없음)

## 6. Histogram (슬라이드 14~16)
- 📘 정의: 데이터셋 **분포의 그래픽 표현**. 구간(interval)별 **빈도 또는 상대 빈도**를 보여줌. **막대 = 각 구간의 데이터 개수**. (슬라이드 14 예: Titanic 데이터의 **Age Distribution**, x=Age, y=Frequency)
- 📘 사용 경우: **데이터 분포 이해** / 데이터의 **모양** 시각화 / **왜도** 평가 / 데이터의 **변동성·퍼짐** 보여주기
- 📘 **함정 — bin(구간) 선택**: 난수 데이터로 **세 가지 binning** 히스토그램 생성 예시
  - **Too Few Bins**(너무 적음): 모양이 뭉개져 정보 손실
  - **Optimal Binning**(적절): 분포 모양이 잘 드러남
  - **Too Many Bins**(너무 많음): 들쭉날쭉해져 노이즈처럼 보임
- 💡 Bar plot과의 차이(➕): **Bar = 범주형 변수**의 크기 비교(막대 사이 간격 있음) / **Histogram = 연속형 변수를 구간으로 나눈 분포**(막대가 붙어 있음).

## 7. 주요 Python 시각화 라이브러리 (슬라이드 17~29)
📘 목록: **Pandas, Matplotlib, Seaborn, Folium, Plotly, PyWaffle**

### Matplotlib (슬라이드 18)
- 📘 **범용(general purpose) 플로팅 라이브러리**, 다른 라이브러리·프레임워크와 잘 통합
- 📘 특징: **다양한 종류의 plot** 생성 / 다양한 요소를 **커스터마이징** / 시각화 작업을 강화

### Pandas (슬라이드 19~20)
- 📘 **데이터 조작(data manipulation)** 에 사용. **plot 기능은 Matplotlib 기반**
- 📘 특징: **Pandas 데이터 구조(DataFrame)와 매끄럽게 통합** / 시각화로 **탐색적 데이터 분석(EDA)**
- 📘 슬라이드 20 코드 예: `df = pd.read_csv('data.csv')` → `df.plot()` → `plt.show()` (matplotlib `pyplot`을 `plt`로 import 후 사용; 칼럼별 선 그래프 4개: Duration, Pulse, Maxpulse, Calories)

### Seaborn (슬라이드 21~23)
- 📘 **특화된 통계 시각화**에 좋음 / **세련된(stylish) plot** 제공
- 📘 특징: 다양한 **색 팔레트와 스타일** / 여러 plot을 **그리드 레이아웃**으로 결합하는 함수 / Pandas와 통합
- 📘 슬라이드 22: 팔레트 종류 — **pastel, muted, bright, deep, colorblind, dark** (가로축 Saturation 채도, 세로축 Luminance 명도). 문서: https://seaborn.pydata.org/tutorial/color_palettes.html

**Matplotlib vs Seaborn 비교표 (슬라이드 23, 한글 표)**

| 구분 | Matplotlib | Seaborn |
|---|---|---|
| **표현력** | 세부 조정 가능 (축, 색상, 선 두께 등 **완전 커스터마이징**) | **통계적 표현(평균, 분포, 회귀선 등)** 을 기본 제공 |
| **디자인** | 기본 스타일은 투박함 → **직접 꾸며야 함** | 기본 디자인이 깔끔 (**논문·보고서에 바로 사용** 가능) |
| **통계 기능** | 단순 시각화 도구 (통계 계산은 별도 라이브러리 필요) | boxplot, violinplot, regression plot 등 **“통계 시각화” 자동 지원** |
| **코드 길이** | bar 하나 그려도 코드가 길어짐 | **같은 시각화를 더 짧은 코드**로 구현 |
| **데이터 처리** | **numpy 배열** 위주로 다룸 | **pandas DataFrame과 친화적** (**컬럼 이름만 지정**하면 됨) |

### Folium (슬라이드 24~25)
- 📘 **지리공간(geospatial) 데이터 시각화**에 탁월 / **인터랙티브하고 커스터마이징 가능한 지도** 제작 / 인기 데이터 분석 라이브러리와 통합
- 📘 슬라이드 25: **Choropleth Map** 이란? ① 지도가 **지리적 구역(행정, 정치 등)** 을 보여주고 ② 구역을 **데이터 값에 따라 색칠**(값 범위 0.00~0.09 … 0.90~0.99 단계별 진하기).

### Plotly (슬라이드 26~27)
- 📘 (슬라이드 원문: “Visualizes categorical” — 오타로 보임) **인터랙티브 대시보드** 구축 / **웹 브라우저**에서 plotting 가능. **Dash by Plotly**와 함께 표시.
- 📘 예: “Avos Analysis Dashboard” — 월별 막대, 도넛 차트 등 여러 차트를 한 대시보드에.

### PyWaffle (슬라이드 28~29)
- 📘 **범주형 데이터를 waffle chart**로 시각화 / 비율(proportion)을 표현하는 **독특한 방식** (정사각형/직사각형 격자). 예: Vehicle Production by Year and Vehicle Type (car / truck / motorcycle)

### 라이브러리 선택 요약
| 이럴 때 | 이 라이브러리 |
|---|---|
| 범용 + 세밀한 커스터마이징 | **Matplotlib** |
| DataFrame 바로 plot, EDA | **Pandas** (`df.plot()`, Matplotlib 기반) |
| 통계 시각화, 예쁜 기본 디자인 | **Seaborn** |
| 지도 (choropleth 등) | **Folium** |
| 인터랙티브 / 웹 대시보드 | **Plotly** (+ Dash) |
| 비율을 격자로 | **PyWaffle** |

## 8. Recap (슬라이드 30)
- 📘 **Line**: 시간에 따른 추세·변화 / **Bar**: 범주·그룹 비교 / **Scatter**: 변수 간 관계 / **Box**: 분포와 이상치 / **Histogram**: 구간별 데이터 분포
- 📘 **Matplotlib**: 폭넓은 plot 기능 / **Pandas**: 데이터 분석과 통합된 plot / **Seaborn**: 통계 시각화 특화, 매력적인 기본 미학·팔레트 / **Folium**: 인터랙티브 지도 / **PyWaffle**: 정사각형·직사각형으로 비율 표현

## 9. 한눈에: 공통 “함정” 정리 (시험 대비)
| Plot | 함정 | 해결 |
|---|---|---|
| Line | y축 스케일 → 변화 과장/축소 | y축 0부터 시작 |
| Bar | y축이 0이 아닌 값에서 시작 | y축 0부터 시작 |
| Scatter | 이상치 | 포함/제외 판단 |
| Box | 이상치 무시/오처리 | 이상치 정보를 해석에 활용 |
| Histogram | bin 수 (too few / optimal / too many) | 적절한 bin 선택 |

## 10. ➕ 다음 실습(DV_05~)을 위한 대응표 (슬라이드 외 추가)
실습 노트에서 plot별 사용 변수를 정리할 때 쓸 틀입니다. 아래는 일반적으로 쓰이는 함수 이름이며, **수업 코드와 다를 수 있으니 실습 파일 받으면 그 코드 기준으로 갱신**하겠습니다.

| Plot | Matplotlib | Pandas | Seaborn | 변수 |
|---|---|---|---|---|
| Line | `plt.plot(x, y)` | `df.plot(kind='line')` | `sns.lineplot(x=, y=, data=)` | x 시간/연속, y 연속 |
| Bar | `plt.bar(x, height)` / `plt.barh` | `df.plot(kind='bar')` | `sns.barplot(x=, y=, data=)` | x 범주, y 수치 |
| Scatter | `plt.scatter(x, y)` | `df.plot(kind='scatter', x=, y=)` | `sns.scatterplot(x=, y=, data=)` | x, y 모두 연속 |
| Box | `plt.boxplot(data)` | `df.plot(kind='box')` | `sns.boxplot(x=, y=, data=)` | y 연속, x 범주(선택) |
| Histogram | `plt.hist(x, bins=)` | `df.plot(kind='hist')` | `sns.histplot(x=, bins=)` | 연속 1개 |
